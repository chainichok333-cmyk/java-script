Объяснение:
Построчная обработка: текст разбивается по \n, каждая строка преобразуется отдельно, а результат склеивается через join("") без переводов строк. Так получается <h1>title 1</h1><h1>alternate title</h1>, как требуют тесты 6, 11, 16 и другие.
Заголовки и цитаты: ^\s* допускает пробелы перед # или >, но не другие символы. Поэтому some text # title 1 и some text > not a quote anymore не превращаются в теги (тесты 5, 10, 15, 47). Заголовки проверяются от ### к #, чтобы ### не поймался как #.
Жирный текст: (\*\*|)(.+?)\1 ищет пару одинаковых маркеров. \1 гарантирует, что  закрывается именно , а  — __. Условие (?!\*|_) нужно для вложенности из теста 48. Для this is a *quote* без него регулярка закрыла бы жирный на первых двух звёздочках и оставила лишнюю * в конце.
Курсив: тот же приём с (\*|_). Жирный обрабатывается раньше курсива, иначе ** разбились бы на два курсива.
